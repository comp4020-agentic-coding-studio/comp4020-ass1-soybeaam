# Breakthrough

The main breakthrough that moved my work forward was changing how I approached using AI. Finding a suitable topic was difficult, and building an interactive site while using tokens efficiently became a challenge. Claude was not always clear about why certain processes were taking so long, so I often had to manually prompt it for updates. Web scraping also took considerable time, and getting the assets and visual design to match what I wanted required many iterations and a large number of tokens. To manage this, I decided to create different agents for specific tasks and, for the first time, became much more conscious of my token usage. I also added a balance catcher to my `claude.md` file to help manage this more effectively.

# What did this work change about who I want to be as a software developer?

This project changed how I see myself as a software developer because I realised I need to adapt my workflow to use AI more efficiently. Creating different agents made me realise that AI can be more useful when I structure the work into smaller, specialised tasks rather than relying on one process to handle everything, especially with webscraping. This approach also helped me manage token usage and made the development process feel more controlled. At the same time, working with `.ts` files showed me that I still need to improve my understanding of the code, as Claude can sometimes make mistakes faster than I can identify and fix them. Moving forward, I want to become better at designing workflows where I can use AI effectively while still understanding and controlling the work it produces.
